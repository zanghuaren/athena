## 1. 阶段目标

做出[01 第 4 节](01-明确目标.md)完成标准里的“可以运行的功能”：

- 02 里所有**必做**功能都实现，接真实模型和真实识别，不留 mock
- 两条演示主线能完整跑通：
  - **学生线**：拍照批改 → 错题入本 → 讲解 → 变式练习 → 复习 → 学情变化
  - **师生线**：老师组卷并布置 → 学生提交 → AI 批改 → 老师复核发布 → 学生看结果 → 老师看学情报告

加分项、正式部署和评测报告不算在本阶段的完成条件里，见第 4 节。

## 2. 开发方式

- 按[技术方案第 11 节](05-技术方案.md)的顺序推进，每一步拆成几**层**，每层可以独立验证，做完就单独提交一次，方便回退
- 每层的完成标准：后端测试通过（连真实 PostgreSQL），前端类型检查和 lint 通过；涉及页面的，在浏览器里按手机和电脑两种宽度实际走一遍
- 代码和文档不一致时，先改文档

这一步定下的做法：

- 章节标题不带“第几章”，编号按年级内顺序（如 `M8-01` 三角形）。人教版 2024 年起逐年换新教材，新旧版章节编号不同，这样两版都对得上；各章所在年级暂按旧版
- 题目文字的写法写进了数据库设计 10.1：公式 `$...$` / `$$...$$`（“$5” 这类钱数不会被当成公式），填空的空 `____`，完形填空的空 `__1__`
- `GET /questions/{id}`：预置题公开，其余只有创建者能看，别人访问返回 404；教师带答案和解析，学生暂时不带。“判分完成后学生能看答案”要依赖作答记录，第 4 步建 `attempts` 时补上
- 题目配图（`content.images`）暂不显示，等文件模块（`files` 表和签名地址）做完再接

实测：

- **答疑首字**：`deepseek-flash` 默认开思考，首字约 2.4 秒；关掉思考后直接调用约 1.5 秒，经过我们的接口约 0.6 秒，满足 ≤ 3 秒
- 引导式讲解能按“点出考点 → 一步一问”进行；负面情绪会先关心、建议找老师家长并给出 12355；闲聊会礼貌拉回学习
- 模型默认用 `\(...\)` 写公式，提示词里要求 `$...$` 后输出正常

和原型不一样的地方（**请确认**）：

- **空状态也显示学科和讲解方式**。原型的空状态没有这两个选择，但 ASK-01 要求提问前能选学科，第一问就按选定的方式讲
- **输入框的发送键在生成时变成“停止生成”**。原型没画这个按钮，ASK-01 要求有
- **AI 助教顶栏加了“历史记录”**。原型的 T-21 没有历史入口，但 ASK-04 的会话管理教师也需要
- 学生电脑端侧栏“最近对话”下面加了“全部对话”，进入 S-02（03 里写了 Web 的历史入口在侧边栏）
- 看过完整解答后，不再显示“再给点提示”“看完整解答”

暂时没做的：

- **图片提问**（ASK-01 附 1 张图）：等文件模块（`files` 表、上传和签名地址），和拍照识题一起做
- **加入错题本、练一道类似的**（ASK-05）：依赖错题本和出题流程，做错题本时接上；`messages.question_id` 也到那时再加

### 5.3 下一步做什么

**第 3 步剩下的：预置题库**（等知识点目录定稿）

1. **题目的稳定编号**：预置题要能重复导入，需要像知识点那样有稳定编号。计划给 `questions` 加一个可空、唯一的 `code` 字段，只有预置题填。先改数据库设计，再加迁移
2. **模型调用**：在 `app/ai/` 接 DeepSeek（openai SDK），模型名从配置读；出题提示词放在 `server/prompts/`
3. **出题脚本**：用 `deepseek-v4-pro` 按知识点出题，每个知识点 5 道，覆盖这个学科常见的题型和难度 1～5。输出先过题目结构校验，不合格的重新生成，结果写到 `server/seed/questions/<学科>.json`，用知识点编号引用
4. **自动核对**：让模型不看答案，独立再做一遍，和标准答案对不上的题标出来，审核时重点看
5. **审核浏览页**：生成一个静态页面，按学科、章节、知识点浏览题目，渲染方式和 App 里一样，标出存疑的题。审核通过的才进种子文件
6. **导入**：`python -m seed` 同时导入题目，`source = preset`，可以重复运行

**第 4 步学生线：答疑已完成，接下来是拍照批改（SCAN）**

1. 文件模块：`files` 表、上传（格式和 10 MB 限制、压缩）、带时效的签名地址；顺带接上答疑的图片提问和题目配图
2. 拍照识题（SCAN-02）：裁剪 → `MODEL_VISION` 识别 → 确认后进入答疑
3. 整页批改（SCAN-03）：`jobs` 表和 Worker、分阶段进度、结果页

整页批改的做法取决于识别测试的结论，最好先把识别测试做完。

**同时进行：第 1 步技术验证的识别测试**

首轮 30 张作业照片已整理在 `eval/homework-ocr/`，还要逐字转写参考答案、人工复核，然后用 `deepseek-flash` 实测题目识别和手写识别的准确率。结果决定拍照批改要不要另加 OCR。照片里的数学、英语目前大多是小学练习，初中的结论还要补拍对应学段的照片再测。
