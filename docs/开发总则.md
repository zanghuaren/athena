参考公司的开发流程，本项目依据如下步骤开发：
| 阶段 | 主要做什么 | 应该产出什么 |
|---|---|---|
| 1. 明确目标 | 给谁用、解决什么问题、第一版做到什么程度 | 项目说明、第一版范围 |
| 2. 梳理需求 | 用户能做哪些事，有哪些条件和限制 | 功能需求文档 |
| 3. 梳理流程与原型 | 用户从哪个页面进入，点完之后去哪里，遇到异常怎么办 | 业务流程、页面清单、低保真原型 |
| 4. UI 设计 | 确定颜色、字体、布局、组件和交互细节 | UI 设计稿、基础设计规范 |
| 5. 技术与接口设计 | 确定技术方案、数据结构、前后端如何交换数据 | 数据库设计、接口约定 |
| 6. 开发 | 实现客户端、后端及必要的管理后台 | 可以运行的功能 |
| 7. 联调与测试 | 验证完整流程、异常情况、兼容性和性能 | 可发布版本 |
| 8. 上线与迭代 | 部署、发布、监控问题、收集反馈 | 持续改进的产品 |
