# 阶段 4：UI 设计

> 状态：初稿 v0.1（2026-11-04）
> 上游：[03-流程与原型](03-流程与原型.md) · 下游：05-技术与接口设计
> 设计稿：[`prototype/index.html`](prototype/index.html)（阶段 3 的可点击原型换上正式视觉后的初稿）
> 视觉来源：旧项目雅典娜设计稿 `reference/eduagent/指导/前端设计/雅典娜美化方案.html`

页面、组件和颜色的具体取值都以设计稿为准，本文只记下开发时要遵守的规则。设计稿也是初稿，开发中会继续调整。

## 1. 风格

- 纸感、书房、安静：米色纸面、陶土红强调、宋体标题，用细线分隔，少用色块和阴影
- 神殿、橄榄枝、回纹只做点缀，不进入正文和操作区
- 主题：纸感书房（浅色，默认）/ 夜间自习（深色）/ 跟随系统

## 2. 规范

- **颜色**：全部走设计稿 `:root` 里的 CSS 变量，深色主题只替换变量值，组件里不写死色值
  - 主色 `clay`（陶土红）：主按钮、选中、链接
  - `olive` 正向（正确、已掌握）、`ochre` 提醒、`danger` 错误和即将截止
  - 掌握度四个等级固定对应：薄弱 `clay`、一般 `ochre`、掌握 `olive`、数据不足 `soft`；热力图也用这四色，不做渐变
- **字体**：标题用宋体（`--serif`），正文用 HarmonyOS Sans / 苹方 / 微软雅黑（`--sans`），数字和英文小标签用 Baskerville（`--latin`）；公式用 KaTeX，渲染失败显示原始 LaTeX
- **布局**：手机按 390px 设计、适配 ≥ 375px，底部 5 个 Tab；Web 左侧栏 184px，阅读内容最大宽 820px；教师 Web 按 ≥ 1280px 设计
- **交互**：所有可操作元素有焦点框；点击区域 ≥ 40px；支持减少动态效果；每页都有加载、空数据、出错三种状态（文案见 02 第 16 节）
