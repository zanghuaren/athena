## 1. 基础数据：知识点与题目（KP）

这一节不对应具体页面，但其他所有模块都依赖它。

### KP-01 知识点体系 · 必做

- 三层结构：**学科 → 章节 → 知识点**；每个知识点标明适用年级
- 范围：人教版（统编版）初中语文、数学、物理、英语全册
  - 语文：七至九年级，按积累与运用、古诗文、现代文阅读、名著阅读、写作等维度组织，不严格按单元（2026-11-05 加入）
  - 数学：七至九年级
  - 物理：八至九年级
  - 英语：七至九年级，按语法、词汇、阅读、写作等维度组织，不严格按单元
- 由开发团队预置维护，用户不能修改
- 规模参考：每科 80～200 个知识点

### KP-02 题目 · 必做

所有来源的题目都用统一的结构：

| 字段 | 说明 |
|---|---|
| 题型 | 单选、多选、判断、填空、解答（含计算、证明、作图说明）；英语额外支持完形填空，英语和语文支持阅读理解（一个材料带多道小题；语文用于现代文、文言文阅读）；**不做听力题** |
| 题干 | 文字 + 公式 + 图片 |
| 选项 | 选择题必填 |
| 答案 | 必填。填空题可以有多个等价答案 |
| 解析 | 分步解析 |
| 知识点 | 1～3 个，必填 |
| 难度 | 1～5 |
| 来源 | 拍照识别 / AI 生成 / 教师录入 / 预置 |
| 归属 | 预置题公开；其余题目只归创建者 |

### KP-03 题目渲染 · 必做

- 支持 LaTeX 公式、化学 / 物理符号和单位、上下标、表格、题干配图
- 公式渲染失败时显示原始 LaTeX 文本，不能显示空白

### KP-04 作答判分规则 · 必做

| 题型 | 判分方式 |
|---|---|
| 单选、判断 | 精确匹配 |
| 多选 | 全对得满分，少选得一半，错选得 0 |
| 填空 | 先和标准答案逐空匹配；不一致时由 AI 判断是否等价（如 `1/2` 和 `0.5`、单位写法不同） |
| 解答 | AI 按评分要点给分，并说明扣分点 |
| 英语作文 | AI 按评分维度给分（加分项，见 PRC-05） |

每次判分产生一条**作答记录**：题目、作答内容、对错、得分、用时、来源（练习 / 作业 / 拍照批改 / 复习）。作答记录是错题、复习和学情的唯一数据来源。

## 2. 账号与体验模式（ACC）

### ACC-01 注册 · 必做

- 填写：用户名、密码、确认密码、身份（学生 / 教师）
- 学生补充：昵称、年级（七 / 八 / 九）
- 教师补充：姓名、任教学科（可多选）、任教年级（可多选）
- **规则**
  - 用户名 4～20 位，字母、数字、下划线，全局唯一
  - 密码 8～32 位，必须同时包含字母和数字
  - 身份注册后不能修改
  - 不收集手机号、邮箱、身份证
- **异常**：用户名已存在 → 提示“用户名已被使用”，保留已填内容

### ACC-02 登录 / 退出 · 必做

- 用户名 + 密码登录；按身份进入学生端对话页（首页）或教师工作台
- 登录状态保持 30 天，退出后清除本机登录状态
- **规则**：同一账号连续输错 5 次密码，锁定 10 分钟
- **异常**：账号或密码错误时统一提示“用户名或密码错误”，不提示具体是哪一项

### ACC-03 忘记密码 · 加分

- 不做自助找回
- 学生可以请班级老师重置（见 CLS-06）；教师账号由开发团队手动处理

### ACC-04 体验模式 · 必做

- 登录页提供“体验学生端”“体验教师端”两个入口，无需注册
- 点击后系统生成一组**体验账号**：
  - 1 名教师 + 1 名可操作的学生，属于同一个班级
  - 班级里另有 30 名虚拟学生，已有 3 次作业的提交和批改数据
  - 可操作的学生已有约 20 道错题、若干条答疑记录和学情数据
- 体验模式下页面顶部常驻“切换到老师视角 / 学生视角”按钮，用来演示师生闭环
- **规则**
  - 每次进入体验都生成一组新的账号，评委之间互不影响
  - 体验账号保留 7 天，到期自动清理
  - 体验账号不能修改密码；每组每天的 AI 调用次数设上限（如 200 次），防止被刷
- **异常**：生成失败 → 提示“体验环境准备失败，请重试”

## 3. 我的（ME）

### ME-01 个人资料 · 必做

- 学生：昵称、头像（从预置头像中选）、年级
- 教师：姓名、头像、任教学科、任教年级
- 学生升年级时手动修改年级，不自动升级

### ME-02 学习偏好（学生）· 必做

- **讲解方式**：引导式（默认）/ 直接讲解；作为 ASK 的默认值
- **常用学科**：决定答疑、练习时默认选中的学科

### ME-03 主题 · 必做

- 纸感书房（浅色）/ 夜间自习（深色）/ 跟随系统；保存在本机（沿用旧设计稿命名）
- 减少动态效果：开启后关闭过渡动画；系统已开启减少动态效果时同样生效

### ME-04 修改密码 · 必做

- 需要输入原密码；体验账号不显示此项

### ME-05 帮助与关于 · 必做

- 使用说明、关于雅典娜、版本号
- 隐私说明：收集哪些数据、老师能看到哪些数据（见第 17 节）

## 4. AI 答疑（ASK）

### ASK-01 发起提问 · 必做

- 输入方式：文字；或附 1 张图片（拍照 / 相册）
- 可选学科：语文 / 数学 / 物理 / 英语 / 自动识别（默认取 ME-02 的常用学科）
- 回答以流式逐字输出，生成过程中可以“停止生成”
- **规则**
  - 单条文字不超过 1000 字
  - 只回答学习相关的问题；明显无关的问题（闲聊、娱乐、不良内容）礼貌拒绝，并引导回学习
  - 超出初中范围的内容可以回答，但要提示“这部分超出了初中要求”
- **异常**：图片识别不出文字 → 回答中说明“没有看清题目”，建议重拍或手动输入

### ASK-02 引导式讲解 · 必做

- 默认模式。AI 先分析题目考查的知识点，然后**一步只给一个提示**，并向学生提问，等学生回应
- 学生可以：
  - 输入自己的想法或答案，AI 判断对错后给下一步
  - 点击“再给点提示”
  - 点击“看完整解答”，直接显示完整步骤
- **规则**
  - 学生答错时指出错在哪，不直接给答案
  - 引导到最后一步或学生点了“看完整解答”后，AI 给出总结：考查的知识点、关键步骤、易错点
- 每个会话可以随时切换引导式 / 直接讲解

### ASK-03 直接讲解 · 必做

- 一次给出完整的分步解答，结尾附总结（知识点、易错点）

### ASK-04 会话管理 · 必做

- 会话列表：按最近更新排序，显示标题（由 AI 根据第一个问题自动生成）、学科、时间
- 支持按关键词搜索、重命名、删除
- 进入历史会话可以继续提问，上下文保持
- **规则**：单个会话超过 50 轮后，提示开一个新会话

### ASK-05 回答后的操作 · 必做

- 对 AI 讲解的题目：
  - **加入错题本**：AI 自动提取题干、正确答案、知识点；学生确认后入本（来源记为“答疑”）
  - **练一道类似的**：生成 1 道同知识点的变式题，在会话内作答
- 对任意回答：举个例子（让 AI 换一个例子再讲一遍）、复制、重新生成

### ASK-06 语音提问 · 加分

- 按住说话，转成文字后填入输入框，学生确认后发送

### ASK-07 教师 AI 助教 · 必做

- 教师端使用同一个对话引擎，但面向教学场景：
  - 解题思路和多种解法
  - 教学设计建议、讲法建议
  - 学生常见错误分析
- 教师端没有引导式模式，也没有“加入错题本”

## 5. 拍照识题与批改（SCAN）

### SCAN-01 拍照入口 · 必做

- 入口：对话页工具栏的“拍照答疑”“作业批改”两个按钮，以及输入框的相机按钮
- 支持拍照和从相册选图；Web 端支持上传图片文件
- 两种模式，由入口决定，拍照页内也可以切换：
  - **拍照答疑**：讲一道题（相机按钮默认这个模式）
  - **作业批改**：批一整页
- **规则**：图片格式 jpg / png / heic / webp，大小不超过 10 MB，系统自动压缩

### SCAN-02 识题讲解 · 必做

- 拍照后显示裁剪框，学生框选要问的那道题
- 识别出题目文字后显示给学生确认，可以手动修改识别结果
- 确认后在当前对话中发送这道题（对话为空时即新会话），按学生的讲解偏好开始讲解（见 ASK-02 / ASK-03）
- **异常**
  - 识别失败或识别为空 → 提示“没有识别到题目”，提供“重新拍照”“手动输入”
  - 一次框选了多道题 → 提示“请只框选一道题”

### SCAN-03 整页批改 · 必做

- 支持一页印刷体题目 + 学生手写作答
- 处理过程分阶段展示进度：识别题目 → 识别作答 → 逐题批改
- 结果页：
  - 原图上每道题标出 ✓ / ✗ / ？（无法判断）
  - 题目列表：每题的题目、学生作答、正确答案、对错、错因
  - 汇总：总题数、正确数、正确率
- 学生可以修改某题的识别结果，然后重新批改这一题
- 错题可以单选或“全部错题加入错题本”（来源记为“拍照批改”）
- 每道错题都可以点“讲解这道题”，进入答疑
- **规则**
  - 一页最多 20 道题，超过的部分提示分开拍
  - 识别置信度低的题目标为“？”，不计入正确率，提示学生核对
  - 解答题按评分要点判断，对、部分对、错三档
- **异常**
  - 整页识别失败 → 提示“照片不清楚”，并给出拍摄建议（光线、角度、平铺）
  - 识别到的不是作业（比如风景照）→ 提示“没有识别到题目”

### SCAN-04 批改记录 · 必做

- 保存每次整页批改的原图和结果，在“我的 → 批改记录”中按时间查看

## 6. 错题本（MIS）

### MIS-01 错题来源 · 必做

| 来源 | 入本方式 |
|---|---|
| 答疑 | 学生手动加入（ASK-05） |
| 拍照批改 | 学生手动加入（SCAN-03） |
| 练习 | 做错自动加入 |
| 作业 | 老师发布批改结果后，错题自动加入 |
| 手动添加 | 拍照或输入题目，自己填写答案 |

- **规则**：同一道题再次做错不重复入本，而是累加“错误次数”，并重新进入复习

### MIS-02 错题列表 · 必做

- 筛选：学科、知识点、来源、状态（待复习 / 复习中 / 已掌握）
- 排序：最近加入、错误次数
- 列表项：题干摘要、学科、知识点标签、一句话提示、复习状态（待复习 / 复习中 · 第 N 次 / 已掌握）、下次复习时间、错误次数；“讲解”“变式练习”按钮
- 错题上**不显示掌握度**：掌握度属于知识点，只在学情画像中显示

### MIS-03 错题详情 · 必做

- 题目、我的作答、正确答案、分步解析、错因
- 错因由 AI 生成，分为：概念不清、计算失误、审题错误、方法不当、粗心、其他；学生可以修改
- 学生可以写笔记（≤ 500 字）
- 操作：讲解这道题（进入答疑）、练变式题、标记已掌握、移出错题本

### MIS-04 变式题 · 必做

- AI 生成 1～3 道同知识点、同难度、换了情境或数字的新题
- 学生在线作答并判分；做对计入掌握度，做错的变式题也进错题本
- **规则**：变式题必须和原题不同，答案经过校验后才展示（校验方式在阶段 5 确定）

### MIS-05 错题集导出 · 加分

- 按筛选条件导出 PDF，可以选择是否包含答案和解析

## 7. 练习（PRC）

### PRC-01 发起练习 · 必做

- 入口：学情画像的薄弱知识点、知识点详情、今日任务的推荐练习、“我的 → 练习记录”
- 设置项：学科、知识点（1～5 个）、题量（5 / 10 / 15）、难度（基础 / 提高 / 挑战）
- 题目优先从预置题库中选，不够的部分由 AI 生成

### PRC-02 作答 · 必做

- 一题一页，可以前后翻；选择题点选，填空和解答题输入文字，解答题也可以拍照上传手写过程
- 显示进度和用时；中途退出时保存进度，下次可以继续

### PRC-03 提交与结果 · 必做

- 提交后判分（规则见 KP-04），结果页显示：得分、正确率、每题对错和解析、涉及知识点的掌握度变化
- 做错的题自动进错题本
- **异常**：AI 判分失败的题目标为“待判分”，后台自动重试，判完后更新结果

### PRC-04 练习记录 · 必做

- 按时间列出历史练习，可以查看每次的结果

### PRC-05 专项训练 · 加分

- **作文批改**：拍照或输入英语作文，AI 按内容、结构、语言、书写给分，并给出修改建议和范文
- **英语口语对练**：选话题，和 AI 语音对话，结束后给出发音和表达的反馈

### PRC-06 记忆卡片 · 加分

- 用于英语单词、物理公式、数学定理
- 学生可以手动建卡，或让 AI 按知识点生成；每次生成保存为一个新卡组，不覆盖旧卡组
- 卡片和错题进入同一个复习队列，按 REV 的同一套规则复习

## 8. 复习（REV）

### REV-01 复习规则 · 必做

- 错题入本后按间隔安排复习：**1 → 2 → 4 → 7 → 15 天**
- 每次复习后学生自评：

| 自评 | 下次复习 |
|---|---|
| 记得 | 进入下一档间隔 |
| 模糊 | 留在当前间隔 |
| 忘记 | 回到第一档（1 天后） |

- 第 5 档（15 天）复习时选“记得”→ 状态变为“已掌握”，不再进入复习
- 学生手动“标记已掌握”的错题，也退出复习

### REV-02 今日复习 · 必做

- 入口：底部“复习”Tab（由旧项目的“知识卡片”Tab 改造）
- 列出所有到期（下次复习时间 ≤ 今天）的错题，以及卡片（如果做了 PRC-06）
- 复习流程沿用旧项目的翻卡交互：先显示题目 → 学生思考或作答 → 翻面看答案 → 自评（忘记 / 模糊 / 记得）
- 客观题可以直接作答，系统判分后再让学生自评
- **规则**
  - 单次最多复习 20 道，剩下的顺延
  - 逾期未复习的题目不会消失，继续留在今日复习里

### REV-03 复习结束 · 必做

- 显示本次复习数量和三种自评的分布，以及明天要复习的数量

## 9. 今日任务（HOME）

学生端的首页是对话页（沿用旧项目）。今日任务是底部的“今日”Tab，由旧项目的“学习计划”页改造而来；Tab 顶部切换“今日任务 / 全部作业”，全部作业见 HW-02。

### HOME-01 今日任务 · 必做

按顺序展示：

1. **待完成作业**：按截止时间排序；12 小时内截止的标红
2. **今日复习**：到期错题数，点击进入 REV-02
3. **推荐练习**：根据学情画像推荐 1～2 个薄弱知识点，点击直接开始练习

- 全部完成后显示“今日任务已完成”

### HOME-02 学情概览 · 必做

- 本周作答题数、正确率、连续学习天数、掌握度最低的 3 个知识点

## 10. 学情画像（PRO）

### PRO-01 掌握度计算 · 必做

- 每个知识点的掌握度 0～100，根据这个知识点**最近 10 次作答**计算，越近的作答权重越高（具体公式在阶段 5 确定）
- 计入的作答来源：练习、作业、拍照批改、复习、变式题；答疑对话不计入
- 等级：

| 掌握度 | 等级 |
|---|---|
| 作答少于 3 次 | 数据不足 |
| 0～59 | 薄弱 |
| 60～84 | 一般 |
| 85～100 | 掌握 |

### PRO-02 学情画像页 · 必做

- 选择学科，按章节展示知识点的掌握度（颜色区分等级）
- 薄弱知识点列表，每项有“去练习”入口
- 掌握度趋势：最近 4 周的平均掌握度变化

### PRO-03 知识点详情 · 必做

- 知识点说明、掌握度、作答记录、相关错题
- 入口：去练习、问 AI 讲讲这个知识点

## 11. 班级（CLS）

### CLS-01 创建班级（教师）· 必做

- 填写：班级名称（如“八年级 3 班”）、学科、年级
- 创建后生成 6 位邀请码（大写字母 + 数字，排除容易混淆的 0 / O、1 / I）
- **规则**
  - 一个班级只对应一个学科；同一批学生的数学课和物理课是两个班级
  - 教师最多创建 10 个班级；每个班级最多 80 名学生

### CLS-02 加入班级（学生）· 必做

- 输入邀请码 → 显示班级名称、学科、老师姓名 → 填写**班级内姓名**（真实姓名，方便老师识别）→ 确认加入
- 加入后立即生效，不需要老师审批
- **规则**
  - 一个学生可以加入多个班级（不同学科的老师）
  - 班级的年级和学生年级不一致时提醒，但允许加入
- **异常**
  - 邀请码不存在 → “邀请码无效，请向老师确认”
  - 已经在这个班级 → “你已经在这个班级中”
  - 班级已满或已归档 → 对应提示

### CLS-03 班级管理（教师）· 必做

- 班级详情：学生名单（班级内姓名、加入时间、作业完成率）、邀请码
- 操作：复制或重置邀请码（重置后旧码失效）、修改班级内姓名、移出学生、归档班级
- 归档后班级只读：不能布置新作业，也不能再加入，历史数据保留

### CLS-04 我的班级（学生）· 必做

- 查看已加入的班级、老师、作业情况；可以退出班级
- 退出后看不到这个班级的新作业；已提交的作业和错题保留

### CLS-05 班级权限 · 必做

- 教师只能看到自己班级的学生和作业数据
- 学生之间互相看不到对方的任何数据

### CLS-06 重置学生密码（教师）· 加分

- 教师可以为本班学生重置密码，生成一次性的临时密码；学生用临时密码登录后必须修改密码

## 12. 作业（HW）与批改（GRD）

### HW-01 布置作业（教师）· 必做

- 题目来源：选一份试卷（PAPER）、从题库挑题、AI 按知识点现出
- 设置项：
  - 标题、布置给哪些班级（同一学科，可多选）
  - 截止时间
  - **提交方式**：在线作答 / 拍照上传 / 两者都可以
  - 是否允许迟交
  - 答案和解析何时对学生可见：发布批改结果后（默认）/ 截止后
- 发布后学生端立即可见
- **规则**
  - 一份作业最多 30 道题
  - 截止时间至少在发布时间 1 小时之后
  - 作业发布后不能改题目，只能修改截止时间或撤回；有学生已经提交的作业不能撤回

### HW-02 作业列表（学生）· 必做

- 分类：待完成、已提交（待批改）、已批改；可以按班级筛选
- 每项显示：标题、班级、截止时间、状态

### HW-03 完成作业（学生）· 必做

- **在线作答**：和 PRC-02 的作答页一致
- **拍照上传**：每页拍一张，最多 10 张，可以调整顺序、删除重拍；提交前系统先识别，提示“第 3 题未识别到作答”这类问题，学生确认后提交
- 可以保存草稿
- **规则**
  - 截止前可以重新提交，以最后一次为准；老师开始复核后不能再提交
  - 截止后：允许迟交的可以提交，标记为“迟交”；不允许的显示“已截止”
- **异常**：图片上传失败 → 单张重试，已经上传成功的不需要重传

### GRD-01 自动批改 · 必做

- 学生提交后立即开始批改：
  - 客观题按 KP-04 规则判分
  - 主观题和拍照提交的作业由 AI 批改，每题给出得分、扣分点、置信度
- 批改完成后，提交状态变为“待复核”
- **异常**：批改失败的题目标为“需人工批改”

### GRD-02 复核批改（教师）· 必做

- 作业详情页：提交情况（已交 / 未交 / 迟交名单）、批改进度
- 逐个学生复核：
  - 左边看原图或在线作答，右边看 AI 的判分
  - 可以修改每题的得分，写整体评语和单题评语
  - 低置信度和“需人工批改”的题目优先显示，并高亮提醒
- 支持“只看有疑问的题”：把全班同一题中 AI 拿不准的作答集中在一起复核
- 复核完成的学生可以单独发布，也可以“全部发布”

### GRD-03 查看批改结果（学生）· 必做

- 只有老师发布后才能看到
- 内容：总分、每题对错和得分、老师评语、答案和解析（按 HW-01 的可见设置）
- 发布后，错题自动进入错题本（来源记为“作业”）

### HW-04 作业记录 · 必做

- 教师：按班级查看所有作业，以及每份作业的完成率和平均分
- 学生：按班级查看所有作业和成绩

## 13. 备课（PREP）与组卷（PAPER）

### PREP-01 生成教案 · 必做

- 填写：学科、年级、课题（从知识点体系选章节或知识点，也可以手动输入）、课时数（1～3）、课型（新授 / 复习 / 习题 / 实验）
- 可选：
  - 关联一个班级，让 AI 参考这个班级在相关知识点上的学情
  - 补充要求（≤ 300 字）
- 生成结构：教学目标、重点难点、教学准备、教学过程（各环节、时间分配、师生活动）、板书设计、课后作业、教学反思（留空）
- 生成过程流式展示，大约 1 分钟

### PREP-02 编辑教案 · 必做

- 在线编辑全文；也可以选中某一段，让 AI 改写（扩写、精简、换一种讲法）
- 自动保存；可以复制一份另存

### PREP-03 导出教案 · 必做

- 导出 Word（.docx），格式规整，可以直接打印

### PREP-04 生成 PPT · 必做

- 两种方式：从已有教案生成；或直接按课题生成（填写内容同 PREP-01）
- 页数 10～25 页，从 3 套模板中选一套
- 生成后在线预览，后台异步生成，大约 2 分钟，显示进度
- 单页修改：改文字，或让 AI 重写这一页；可以增删页、调整顺序
- 导出 .pptx
- **异常**：生成失败 → 保留填写的参数，可以重试

### PAPER-01 AI 组卷 · 必做

- 设置：学科、年级、知识点范围、题型和题量（如单选 10、填空 5、解答 3）、难度分布、总分
- 系统先从预置题库选题，不够的部分由 AI 生成；生成的题目在页面上标明“AI 生成”
- 出卷后可以：替换某题（同知识点同题型换一道）、编辑题目、调整顺序、修改分值
- 系统检查并提示：总分是否等于设置、知识点覆盖情况

### PAPER-02 试卷管理 · 必做

- 我的试卷列表；复制、删除
- 导出 Word：学生版（不带答案）、教师版（带答案和解析）
- 一键布置为作业（进入 HW-01，题目已带入）

### PAPER-03 个人题库 · 加分

- 收藏试卷中的题、手动录入、拍照录入题目；按知识点和题型筛选；组卷和布置作业时可以从题库选

### PREP-05 备课记录 · 必做

- 我的教案、我的 PPT 列表，可以按学科、课题搜索

## 14. 学情分析（ANA）

### ANA-01 班级学情 · 必做

- 选择班级和时间范围（最近一次作业 / 最近一个月 / 全部）
- 指标：作业完成率、平均分、正确率
- **知识点热力图**：按章节列出知识点，用颜色表示全班平均掌握度
- 高频错题：错误率最高的 10 道题，可以点开看全班作答分布
- 学生排行：按正确率排序，突出需要关注的学生（掌握度明显低于班级平均）

### ANA-02 单个学生学情 · 必做

- 该学生的知识点掌握度、作业成绩趋势、错因分布、薄弱知识点
- **规则**：只统计这个班级的作业数据，见第 17 节

### ANA-03 单次作业分析 · 必做

- 每道题的正确率、得分分布、常见错误答案

### ANA-04 AI 学情报告 · 必做

- 针对班级或单个学生生成报告：整体情况、主要问题、知识点诊断、教学建议（下节课讲什么、哪些学生需要个别辅导）
- 报告中的数字必须来自统计数据，AI 只负责解读，不编造数字
- 可以编辑，导出 Word / PDF
- **规则**：作业数据少于 1 次时不能生成，提示“数据不足”

## 15. 消息提醒（MSG）· 加分

- App 内消息中心，不做系统推送
- 学生：新作业发布、作业即将截止（提前 12 小时）、批改结果已发布
- 教师：作业截止时的提交汇总、AI 批改完成待复核
- 有未读消息时显示红点

## 16. 通用规则与异常

| 场景 | 处理方式 |
|---|---|
| 断网 | 页面顶部提示“网络已断开”；已加载的内容可以继续看；需要联网的操作按钮置灰 |
| 请求超时 | 普通请求 15 秒超时，提示“请求超时”并提供重试；AI 生成类按各自的时间要求处理 |
| AI 生成中断 | 保留已经生成的部分，提示“生成中断”，提供“继续生成 / 重新生成” |
| 长任务（PPT、整页批改、报告） | 后台执行，离开页面不会中断；完成后在原入口能看到结果（如果做了 MSG，还会有消息提醒） |
| 登录过期 | 跳转登录页，登录后回到原页面；未提交的草稿保存在本机 |
| 无权限 | 提示“没有权限访问”，返回上一页 |
| 内容不存在或已删除 | 提示“内容不存在或已被删除” |
| 空数据 | 每个列表都有空状态说明和下一步引导，比如错题本为空时提示“拍照批改一份作业试试” |
| 输入不合法 | 在输入框下方即时提示，不能等到提交后才弹窗 |
| 重复提交 | 提交按钮点击后立即置灰，直到返回结果 |
| AI 输出内容不当 | 系统拦截并替换为“这个问题我没办法回答”，同时记录日志 |
| 体验账号次数用完 | 提示“今日体验次数已用完”，查看类功能仍可使用 |

## 17. 数据可见性与隐私

| 数据 | 学生本人 | 班级教师 | 其他学生 |
|---|---|---|---|
| 资料（昵称、年级） | ✓ | 只看班级内姓名 | ✗ |
| 作业作答和成绩 | ✓ | ✓ | ✗ |
| 作业产生的错题 | ✓ | ✓（通过学情分析） | ✗ |
| 答疑记录 | ✓ | ✗ | ✗ |
| 自主练习、拍照批改、复习 | ✓ | ✗ | ✗ |
| 学情画像（全部来源） | ✓ | ✗，老师只看基于本班作业的学情 | ✗ |

**理由**：学生的自主学习对老师不可见，学生才敢放心提问、暴露问题。这一点可以作为答辩中的设计亮点。

- 用户删除的会话、错题直接删除，不保留
- 体验账号的数据 7 天后清除

## 18. 非功能需求

### 18.1 性能

| 场景 | 要求 |
|---|---|
| 页面打开 | ≤ 2 秒 |
| 答疑首字出现 | ≤ 3 秒 |
| 单题识别 | ≤ 8 秒 |
| 整页批改（10 道题以内） | ≤ 45 秒，过程中有分阶段进度 |
| 练习 / 在线作业判分 | 客观题 ≤ 1 秒；含主观题 ≤ 20 秒 |
| 教案生成 | ≤ 90 秒，流式展示 |
| PPT 生成 | ≤ 3 分钟，显示进度 |
| 组卷 | ≤ 60 秒 |
| 学情报告 | ≤ 60 秒 |
| 并发 | 支持 100 人同时在线（一个试用班级 + 评委） |

### 18.2 AI 效果指标（作为答辩的评测数据）

每个学科建立评测集，每科 ≥ 100 道题，覆盖各年级和题型：

| 指标 | 目标 |
|---|---|
| 题目识别准确率（印刷体） | ≥ 95% |
| 手写作答识别准确率 | ≥ 85% |
| 客观题批改准确率 | ≥ 95% |
| 解答题批改与教师评分一致率 | ≥ 80% |
| 讲解正确率（人工抽检） | ≥ 90% |
| 变式题 / AI 出题可用率（人工抽检，无错误、符合知识点） | ≥ 90% |

### 18.3 兼容性

- Android 10 及以上，屏幕 5.5～7 英寸；平板可用即可
- Web：最新两个版本的 Chrome / Edge；教师端按 ≥ 1280 px 宽度设计；学生端 Web 适配 ≥ 375 px
- 两端数据实时同步：在一端的操作，另一端刷新后可见

### 18.4 安全

- 密码加密存储，传输全程 HTTPS
- 每个请求都在服务端校验数据归属，不依赖前端隐藏
- 上传的图片只有本人和有权限的老师能访问，链接有时效
- 模型 API Key 等密钥只在服务端，不进入客户端和日志

### 18.5 内容安全（未成年人）

- AI 只回答学习相关的问题；对危险、暴力、色情、引导自伤等内容拒绝回答，并给出正向引导
- 识别到学生表达明显负面情绪时，AI 给予关心，并建议联系老师或家长
- 输入和输出经过敏感词过滤

### 18.6 可演示性

- 演示环境独立部署，和试用环境分开
- 关键演示流程准备好预置数据和兜底方案（例如模型服务不可用时，可以切换到备用模型）

## 19. 加分项的实施顺序

必做功能完成后，按以下顺序做加分项：

1. 记忆卡片（PRC-06）
2. 作文批改（PRC-05）
3. 错题集导出（MIS-05）
4. 消息提醒（MSG）
5. 英语口语对练（PRC-05）
6. 个人题库（PAPER-03）

其余加分项（语音提问 ASK-06、重置学生密码 CLS-06）视时间安排。
