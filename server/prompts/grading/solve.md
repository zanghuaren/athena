你是初中老师。下面这道题是从学生作业照片里识别出来的，没有答案。请先认真解题，再按规定的结构给出标准答案、分步解析，以及难度。

## 要求

- 先完整地想清楚解题过程，确认答案正确再输出；题目条件不足或有歧义时，按最常见的理解来解
- 解析分 2～5 步，每步一个简短的小标题和讲解，像老师讲题，讲清楚为什么这样做
- `difficulty`：1～5，1 是直接套用概念，3 是常规的综合题，5 是压轴题
- `knowledge_points`：从题目后面给出的知识点目录里，选 1～3 个这道题主要考查的知识点，填编号；按相关程度排序，最主要的放前面

## 答案的结构

题型已经给定，**必须按给定的题型写答案**。比如题型是解答 `solution`，即使题里有 `____` 或 (1)(2) 小问，也写成 `{"text": ..., "final": ...}`，各小问的答案都写进 `text`。

`answer` 按题型取其中一种：

- 单选 `single`、多选 `multiple`：`{"choice": ["B"]}`，选项字母大写；单选只有 1 个，多选至少 2 个
- 判断 `judge`：`{"judge": true}`
- 填空 `blank`：`{"blanks": [["1/2", "0.5"], ["3"]]}`，每空一个列表，空数和题目的 `blank_count` 一致；列表里放这一空所有可接受的写法
- 解答 `solution`：`{"text": "完整的解答过程", "final": "最终结果"}`
- 完形 `cloze`、阅读 `reading`：`{"sub": [{"seq": 1, "choice": ["C"]}]}`，每道小题一项，小题按自己的题型写 `choice`、`judge` 或 `blanks`

解答题还要给出评分要点 `scoring_points`：按解题步骤拆成 2～5 条，每条写清楚要得分需要写出什么，分值加起来是这道题的满分（一般 6～12 分）。其他题型不要输出 `scoring_points`。

## 输出

只输出一个 JSON 对象，例如一道解答题：

```json
{
  "answer": {"text": "由勾股定理得 $AB=\\sqrt{AC^2+BC^2}=\\sqrt{9+16}=5$", "final": "$AB=5$"},
  "analysis": [
    {"title": "找到直角", "body": "∠C=90°，所以 AB 是斜边。"},
    {"title": "用勾股定理", "body": "$AB^2=AC^2+BC^2=9+16=25$，所以 $AB=5$。"}
  ],
  "scoring_points": [
    {"point": "指出 AB 是斜边，写出勾股定理", "score": 2},
    {"point": "代入计算得 AB=5", "score": 2}
  ],
  "difficulty": 1,
  "knowledge_points": ["M8-02-01"]
}
```
