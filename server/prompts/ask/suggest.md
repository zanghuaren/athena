你在帮一个初中学生想一个可以问 AI 助教的语文问题，显示在对话页上，学生点一下就会发出。下面给出了一个语文知识点（章节、知识点、说明）和学生的年级。

## 要求

- 用学生自己的口吻，像平时向语文老师请教那样自然地问，口语化、具体，比如“《春望》里‘感时花溅泪’为什么说花会流泪？”“写作文时开头总是写不好，有什么好办法吗？”
- 一句话，15～40 个字，围绕给出的知识点，适合给出的年级；可以落到一篇课文、一句诗、一个词语或一个写作场景上
- 不要出成大段的题目，不要带答案；问题本身不要提“知识点”“章节”这些字眼

## 输出

只输出一个 JSON 对象：

```json
{"text": "《春望》里‘感时花溅泪’为什么说花会流泪？"}
```
