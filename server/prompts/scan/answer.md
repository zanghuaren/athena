图片是从一页作业照片上裁下来的一块，里面有一道题和学生手写的作答；为了不切掉作答，裁的范围放宽了，边上可能露出相邻题目的一部分。题目已经识别好，在下面给出。请读出学生对**这一道题**的作答。

## 要求

- 只读这道题的作答，按题干和题号找到它；相邻题目的作答不要读进来
- 照录学生写的内容，不改正、不补全、不替学生解题；学生写错了也照写
- 老师用红笔写的订正、批改符号（✓、✗、分数、评语）不算学生的作答
- 学生划掉的字不算；划掉后在旁边重写的，以重写的为准
- 学生没有作答的空或题，照实给空的作答，不要猜
- 字迹看不清、被遮挡、或在图里找不到这道题：`status` 为 `unclear`，不要猜

## 作答的结构

`answer` **按给定的题型**取一种。题型是解答时，即使题里有 `____` 或 (1)(2) 小问，也把学生的全部作答按顺序写进 `text`，如 `（1）……\n（2）……`：

- 单选、多选：`{"choice": ["B"]}`，没选就是 `[]`
- 判断：`{"judge": true}`，学生写 ✓、T、对 为 `true`，写 ✗、F、错 为 `false`，没写为 `null`
- 填空：`{"blanks": ["5", "增大"]}`，按空的顺序，个数和题目的空数一致，没填的空写 `""`
- 解答：`{"text": "学生写的完整过程和结果"}`，公式用 `$...$`，分行照学生写的分行；没写为 `""`
- 完形、阅读：`{"sub": [{"seq": 1, "choice": ["C"]}, {"seq": 2, "blanks": ["went"]}]}`，每道小题一项，按小题的题型写 `choice`、`judge` 或 `blanks`

## 输出

只输出一个 JSON 对象：

```json
{"status": "ok", "answer": {"blanks": ["10⁴Pa", "2500Pa"]}, "confidence": 0.9}
```

- `status` 为 `unclear` 时 `answer` 为 `null`
- `confidence`：0～1，你读出的作答有多可靠；字迹潦草、有涂改、不确定是哪道题的作答时写低
