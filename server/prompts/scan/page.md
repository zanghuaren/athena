图片是学生拍下的一页初中作业（数学、物理或英语），上面有印刷的题目和学生手写的作答。请找出这一页上的每一道题，转写题目，并标出每道题在图上的位置。这一步只转写题目，不转写学生的作答。

## 判断

- 图里没有题目（风景、人物、空白页）：`status` 为 `empty`
- 照片模糊、太远、太暗，大部分题目的字看不清：`status` 为 `unclear`。不要猜，看不清就说看不清
- 否则 `status` 为 `ok`

## 拆题

- 按题号拆，一个题号一道题；同一题号下的 (1)(2) 小问合成一道题
- 大题下面带编号的小题各算一道（如“一、选择题”下面的 1、2、3）；大题标题本身不算题
- 完形填空、阅读理解：整篇材料和它的小题合成一道题
- 只露出一部分、被裁掉大半的题不要

## 题型和题目内容

`type` 取：`single` 单选、`multiple` 多选、`judge` 判断、`blank` 填空、`solution` 解答（计算、证明、作图、简答、翻译、写句子都算）、`cloze` 完形填空、`reading` 阅读理解。

- 题干里有横线或括号让学生填一个词、一个数、一个短语的，就是**填空**，几个空、有没有 (1)(2) 都一样
- 要写出计算过程、证明、理由、句子的，才是**解答**；同一题里既有空又有要写过程的小问，按解答

`content` 的结构：

- 所有题型都有 `stem`：题干的 Markdown
- 单选、多选：`options`，如 `[{"key": "A", "text": "..."}]`，选项内容不要再写进 `stem`
- 填空：`blank_count` 是空的个数，`stem` 里每个空写成 `____`（括号里要填的也写成 `____`）
- 完形、阅读：`material` 是短文，完形的空写成 `__1__`、`__2__`；`sub_questions` 是小题，每题 `{"seq": 1, "type": "single", "stem": "...", "options": [...], "score": 1}`，小题题型只能是 `single`、`multiple`、`judge`、`blank`（填空的小题要有 `blank_count`），`score` 都写 1
- 其他题型不要输出 `options`、`blank_count`、`material`、`sub_questions`

转写规则：

- 只转写印刷的题目；学生写的答案、老师的红笔批改、页码、大题标题都不转写
- 原文照录，不改写、不补全、不解答；看不清的个别字写成 `□`
- 表格用 Markdown 表格，第二行是 `| --- | --- |`；图形用文字简单说明，如“（图：直角三角形 ABC，∠C=90°）”
- 公式用 `$...$`，不要用 `\(...\)`；简单的符号（∠、°、△、²、√、π、×、÷）直接写
- 英语题保留原文，不翻译

## 位置

`bbox` 是 `[x1, y1, x2, y2]`：这道题所在区域的左上角和右下角，按图片宽高换算成 0～1000 的整数（左上角是 `[0, 0]`，右下角是 `[1000, 1000]`）。区域要包住**题目和学生在这道题上写的作答**。

## 输出

只输出一个 JSON 对象：

```json
{
  "status": "ok",
  "subject": "math",
  "questions": [
    {
      "seq": 1,
      "type": "single",
      "content": {"stem": "下列各数中，最小的是（　）", "options": [{"key": "A", "text": "$-2$"}, {"key": "B", "text": "$0$"}]},
      "bbox": [52, 80, 948, 190],
      "confidence": 0.95
    }
  ]
}
```

- `seq`：按页面上从上到下、从左到右的顺序从 1 编号
- `subject`：`math`、`physics`、`english` 之一；`status` 不是 `ok` 时为 `null`，`questions` 为空列表
- `confidence`：0～1，这道题的题目转写有多可靠；字迹模糊、被遮挡、被裁掉一部分时写低
