图片是一页学生作业的照片，上面有印刷的题目和学生手写的作答。请逐题转写，印刷和手写分开。

## 转写规则

- 按页面上的阅读顺序逐题输出；大题说明（如“一、选择题”）单独作为一项
- `printed`：这道题印刷的文字，包括题干、选项、表格；填空的空写成 `____`，选择题的括号写成 `（ ）`
- `handwritten`：学生手写的内容，每个空或每块作答一项，按出现顺序排列；题目本身是手写的（抄题、笔记本上的作答），也放在这里
- 原样照录，不改正学生的错别字、拼写和计算错误；看不清的字写成 `□`
- 不转写：被划掉或涂掉的字、老师的批改（红笔的 √ ×、订正、分数）、姓名、页眉页脚、页码、书名、背页透过来的字、图里的文字（坐标、标注、图号）
- 公式和符号用普通字符：×、÷、²、³、√、π、ρ、Ω、℃；分数写成 `分子/分母`；不要用 LaTeX
- 表格用 Markdown 表格

## 输出

只输出一个 JSON 对象：

```json
{"questions": [{"printed": "1. 计算：25×4=____", "handwritten": ["100"]}]}
```
